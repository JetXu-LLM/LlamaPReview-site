02 / GET STARTED

Install, open a PR, read the review

  1. Install the GitHub App and select the public repositories you want reviewed.
  2. Open a non-draft pull request, or mark a draft ready for review.
  3. Read the review on GitHub and check its findings against the code.

The app does not review every push. Reviews use GitHub's COMMENT state, not APPROVE or REQUEST_CHANGES, and are not a required merge check.

Hosted capacity and limits

Free hosted capacity: up to 3 admitted review attempts per repository per UTC day, within a shared 100-attempt daily limit. An attempt does not guarantee a completed review. Over-capacity requests are skipped, not queued.

Capacity policy · Failure and skip messages

Reviews can miss issues or be wrong; they supplement your tests and review process. Evidence retrieval is bounded, and missing coverage remains a gap.

04 / RUN YOUR OWN

Self-host in your AWS account

Run the public-repository review pipeline in your own AWS account. Supply your own GitHub App and model-provider credentials, and pay your own AWS and provider costs.

The reference Terraform stack disables hosted quota counters by default and leaves one-time head succession enabled. New source installations default to an OpenRouter GPT-6 Luna max trial with documented qualification limits. The existing DeepSeek profile remains selectable. This source default is separate from the hosted service, which uses DeepSeek.

Data and privacy

New private-repository events stop after signature verification and minimum visibility parsing, before durable product storage, provider calls or GitHub product API calls. For eligible public requests, selected evidence, prompts and output are sent to DeepSeek.

Hosted public-run records and artifacts expire in 30 days; full provider traces in 7. Expiry is not an immediate deletion guarantee. Read the Privacy Policy and security model.
